# Organic-Vegetables-Portal
A Django-based web application connecting farmers with housing society residents for organic vegetable enquiries, featuring user authentication, enquiry management, and SQLite database integration.
css/ – Contains compiled CSS files used for website styling and layout.

js/ – Contains JavaScript files responsible for frontend functionality and interactivity.

img/ – Stores website images, icons, logos and other visual assets.

scss/ – Contains SCSS source files used for organized and maintainable styling.

vendor/ – Stores third-party libraries, frameworks and external frontend dependencies.
